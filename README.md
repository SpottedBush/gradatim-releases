# Gradatim : versions de l'app

Les versions de Gradatim, l'app de coaching League of Legends de Spotted Bush (bêta fermée, sur invitation).

- **Installer** : télécharge `Gradatim-<version>-setup.exe` dans la [dernière version](https://github.com/SpottedBush/gradatim-releases/releases/latest).
- **Mettre à jour** : rien à faire, l'app installe toute seule les nouvelles versions signées.
